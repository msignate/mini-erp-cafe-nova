# Mini-ERP Café Nova

Mini-ERP pédagogique créé pour l'exposé « L'ERP Sage » (Master 2 Data & IA, management de l'innovation).

Gérez un torréfacteur fictif en 8 missions : devis, facture, écriture comptable automatique, facture électronique, encaissement et lettrage, TVA, assistant IA. Un quiz de 10 questions est inclus.

Ce n'est pas un logiciel Sage : données fictives, comptabilité simplifiée, pour comprendre la logique d'un ERP.

Groupe : Maïmouna Signaté, Linda Boukhit, Nassim Mezzai, Bachar Ben Slama, Alain Evina, Leonnel Hernández Aguirre.
